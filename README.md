# 🤖 AI Text Analyzer

A simple and powerful AI-powered web app that analyzes the sentiment of text using Machine Learning.

---

## 🚀 Features

- 🔍 Real-time sentiment analysis
- 🤖 Powered by Hugging Face Transformers
- ⚡ FastAPI backend
- 🌐 Simple and clean UI
- 📦 Lightweight and beginner-friendly

---

## 🛠️ Tech Stack

- Python 🐍
- FastAPI ⚡
- Transformers (Hugging Face) 🤗
- HTML + JavaScript 🌐
